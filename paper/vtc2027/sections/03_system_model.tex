\section{System Model and Reproducibility}
\subsection{Propagation and link abstraction}
The large-scale A2A channel uses the 3.5~GHz measurement-derived fit of Erdemir \emph{et al.} \cite{erdemir2023a2a},
\begin{equation}
 PL(d)=34.650+21.66\log_{10}(d/1\text{ m}).
\end{equation}
Simulated RF values are model-derived, not field measurements. The study profile uses 50~MHz, 30~kHz SCS, 133 PRBs, and 0.5~ms slots; 133 PRBs for 50~MHz/30~kHz is consistent with the NR UE bandwidth table \cite{3gpp38101}. MCS values, TBS quantization, and LDPC segmentation follow NR procedures \cite{3gpp38212,3gpp38214}, but the resource grid is an explicit study profile rather than a complete PSSCH implementation: each slot reserves two control/PSCCH-like symbols and one guard symbol, uses 11 PSSCH symbols, and removes 24 DM-RS RE/PRB. PSFCH, SL-PRS, and detailed first/second-stage SCI RE accounting are not modeled explicitly.

For each candidate MCS, the computed TBS determines base graph and nominal code-block size. The requested code-block size is mapped to the nearest available 5G-LENA curve with the same MCS/base graph; BLER is linearly interpolated in SINR and clamped to the sourced curve endpoints. Transport-block BLER is derived from code-block BLER under an independent-code-block approximation. These are generic NR EESM link-level simulation tables from 5G-LENA \cite{patriciello2019e2e,ferreira2026lena}, not measured UAV or PSSCH-specific BLER data. Link adaptation selects the available MCS maximizing expected first-transmission delivered bits per slot; a fixed-MCS-4 control tests this optimistic instantaneous-SINR assumption.

\subsection{Topology and interference controls}
For swarm size $N$, the simulator forms $\lfloor N/2\rfloor$ one-way disjoint transmitter--receiver links; all formed links transmit simultaneously in each static snapshot and one UAV is unpaired when $N$ is odd. The baseline pairs node indices $(0,1),(2,3),\ldots$, so desired-link distance is independent of proximity. The robustness topology instead globally sorts pairwise distances and greedily selects the shortest non-overlapping pairs; we call this \emph{greedy short-link pairing}, not a standardized association rule.

The 133 PRBs are partitioned as evenly as possible across $R\in\{1,2,4,8\}$ abstract frequency resources. Different resources are assumed perfectly orthogonal, i.e., no adjacent-channel/inter-carrier leakage is modeled. For $R>1$, the baseline reuse allocator forms the symmetric geometric conflict weight
\begin{equation}
 w_{ij}=d^{-2}(\mathrm{Tx}_i,\mathrm{Rx}_j)+d^{-2}(\mathrm{Tx}_j,\mathrm{Rx}_i),
\end{equation}
orders links by total conflict weight, and greedily assigns each link to the resource with minimum accumulated same-resource weight. This is a research abstraction, not NR Mode-1/Mode-2 sensing or scheduling \cite{garcia2021nrv2x}. Seeded random assignment is the no-coordination control. Directional relative advantage $G\in\{0,3,6,9\}$~dB is imposed as $+G/2$~dB desired gain and $-G/2$~dB co-channel interference gain; it is a sensitivity variable, not a beamforming model.

\subsection{Metrics, statistics, and evidence}
First-TX success probability is $1-\mathrm{TB\!\!\!-BLER}$. Expected PHY goodput is $\mathrm{TBS}\,(1-\mathrm{TB\!\!\!-BLER})/0.5$~ms under one scheduled TB per active link per slot; it excludes queues, higher-layer overhead, retransmission timing, and scheduler idling. Primary treatment comparisons reuse identical seeds/geometries and report paired differences, Cohen's $d_z$, and deterministic paired-bootstrap 95\% intervals.

The operating envelope is an explicit engineering-policy summary: a scenario is \emph{mean-policy-qualified} when its scenario-mean first-TX success probability is at least 0.10 and mean expected PHY goodput is at least 1~Mbps. Thresholding uses mean point estimates, not lower confidence bounds, so the reported largest evaluated $N$ is not a capacity guarantee.

Code, deterministic seed definitions, compact publication extracts, and workflow provenance are versioned in the public repository,\footnote{\url{https://github.com/panagiotagrosdouli/uav-sidelink-swarm}} while full per-seed evidence is archived by the cited GitHub Actions artifact. The audited publication run used commit \texttt{f224ba9e5f95} and stores the manuscript snapshot, generated tables, and artifact digest together.
