# Experiment 001 — Measurement-derived A2A path-loss validation

## Objective

Validate the reusable Python implementation of the published 3.5 GHz A2A large-scale path-loss fit before using it inside a many-UAV swarm simulation.

## Primary scientific source

U. Erdemir, B. Kaplan, I. Hokelek, A. Gorcin, H. A. Cirpan, **Measurement-based Channel Characterization for A2A and A2G Wireless Drone Communication Systems**, 2023 IEEE 97th Vehicular Technology Conference (VTC2023-Spring), DOI: `10.1109/VTC2023-Spring57618.2023.10199853`.

Open manuscript: arXiv:2306.08474.

## Verified campaign parameters

- center frequency: 3.5 GHz;
- bandwidth: 50 MHz;
- transmitted power: 30 dBm;
- two DJI Matrice 600 Pro UAVs;
- A2A altitude: 100 m for both UAVs;
- initial separation: 85 m;
- TX speed: 3 m/s;
- TX route: 1 km straight trajectory;
- measurement recording period: 100 ms.

The paper reports the A2A fit parameters in Table II as `eta = 2.166` and `PL0 = 34.650 dB`.

## Model

The repository reproduces the reported log-distance fit as

`PL(d) = 34.650 + 10 * 2.166 * log10(d / 1 m)`.

This is a **measurement-derived large-scale model**. Evaluated values generated by Python are DERIVED outputs, not the original raw measurement samples.

## Implementation

Reusable implementation:

`src/channel_models/measured_a2a.py`

Route-based reproduction helper:

`src/measured_a2a_baseline.py`

Configuration/provenance:

`config/measured_a2a_35ghz.yaml`

## Validation tests

`tests/test_measured_a2a.py` checks:

1. `PL(1 m) = PL0`;
2. the 10 m value against direct manual substitution;
3. monotonic increase over 1/10/100/1000 m;
4. rejection of negative distance.

Run:

```bash
python -m pytest -q
```

Run the reproduction helper:

```bash
python -m src.measured_a2a_baseline
```

## Limitations

- The repository does not currently contain the original GPS/raw channel-measurement dataset.
- The route helper reconstructs travelled distance from the reported geometry; it is not a replay of raw GPS samples.
- The model represents large-scale path loss only; it does not reproduce the complete measured channel impulse response, multipath fading, or RMS delay-spread time series.
- No many-UAV interference, SINR, PDR, receiver noise figure, or NR sidelink scheduler parameter is claimed to be measured by this experiment.

## Next step

Use this validated channel function as one selectable propagation model inside the many-UAV simulator, while keeping swarm geometry, traffic, receiver assumptions, and scheduling explicitly classified as SYNTHETIC / EXPERIMENTAL_SWEEP / STANDARD as appropriate.
